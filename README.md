# Парсер стоматологий без сайта (РФ)

Статус: **заготовка, кода ещё нет.** Папка и репозиторий подключены заранее, по прямому запросу владельца, чтобы CI/CD-пайплайн можно было настроить сразу, как только появится код.

## Идея

Найти по России стоматологические клиники без собственного сайта — потенциальные клиенты на разработку сайта.

## Важное ограничение (не снято)

Рассылка/питч с формулировкой в духе «Минздрав и РКН теперь требуют сайт, иначе штраф» **не отправляется и не пишется**, пока не проверена точная юридическая формулировка требования. Это отдельная задача, ещё не выполненная — см. память по этому проекту.

## Дальше

Нужна конкретика от владельца: источник данных для парсинга (2ГИС, Яндекс.Карты, etc.), объём (город/регион/вся РФ), формат вывода.
